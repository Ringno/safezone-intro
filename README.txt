# 안전지대 소개 사이트

## GitHub Pages 올리는 가장 쉬운 방법
1. GitHub에서 새 저장소(repository)를 만듭니다. 예: `safezone-intro`
2. 이 ZIP을 풀고 `index.html`, `style.css`, `assets` 폴더를 저장소 최상단에 업로드합니다.
3. GitHub 저장소 → Settings → Pages
4. Build and deployment에서 `Deploy from a branch`
5. Branch를 `main` / `(root)`로 선택 후 Save
6. 잠시 후 `https://사용자이름.github.io/safezone-intro/` 주소가 생깁니다.

## Crack 상세설명에서 배너 클릭 링크 예시
크랙이 Markdown 이미지 링크를 지원한다면:

[![세계관 소개](배너이미지URL)](https://사용자이름.github.io/safezone-intro/)

HTML을 지원한다면:

<a href="https://사용자이름.github.io/safezone-intro/" target="_blank">
  <img src="배너이미지URL" alt="세계관 소개">
</a>

※ 실제 크랙 에디터에서 허용하는 문법에 맞춰 사용하세요.
